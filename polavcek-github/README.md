# Polavček Redesign

Landing estatica para presentar una version moderna de la web de Polavček, preparada para revisar en GitHub y publicar con GitHub Pages.

## Archivos

- `index.html`: estructura y contenido de la landing.
- `styles.css`: estilos responsive, paleta y componentes visuales.
- `script.js`: menu movil y pequenos comportamientos de interfaz.

## Ver en local

Abre `index.html` directamente en el navegador o usa un servidor local:

```bash
python3 -m http.server 8000
```

Despues entra en:

```text
http://localhost:8000
```

## Publicar en GitHub Pages

1. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raiz del repositorio.
2. En GitHub, entra en `Settings > Pages`.
3. En `Build and deployment`, selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/root`.
5. Guarda los cambios.

La URL tendra normalmente este formato:

```text
https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/
```
